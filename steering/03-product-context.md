# 产品背景与核心概念

本文件包含产品定位、品牌基因、竞品分析等背景信息。在需要理解产品方向时通过 `#03-product-context` 引用。

## 项目概述

**MofunShow - Elian**（魔方秀）是一款 AI 驱动的英语学习 App，通过 AI-native visual dialogues（AI 原生视觉对话）让英语背后的意义、情绪、关系、文化和选择变得可见、可模仿、可说出。这是对 2013-2020 年"英语魔方秀"（400万用户）的完全重建，从 PHP 后端升级为 React Native + CloudBase 无服务器架构。

**核心创新**: AI-native visual dialogues + Elian AI 伙伴学习。不是用 AI 模仿电影，而是创造电影做不到的语言学习体验——让一句英语背后的意义变得可见。

## 两个支柱

1. **Dialogos Video** — AI-native visual dialogues for language learning。不是"看 AI 视频学英语"，而是"看见意义，说出英语"
2. **Elian** — 全程陪伴的学习伙伴，有记忆、有理解力

## 品牌基因

**MofunShow = "魔方秀" (Magic Cube Show)**
- **Magic (魔力)**: 游戏化（魔法币、能量、连续记录）
- **More Fun → Mofun (音译) → 魔方**: 各种有趣组合形成魔方般的体验
- **Learning (学习)**: 教育温暖与鼓励
- **Show (表演)**: 娱乐、表演、配音创意

**品牌个性**: Friendly Mentor + Creative Director

**Slogan 演化**:
- 旧版：`More fun, more English` / `看电影，学英语` / `看电影，品文化，学英语`
- 新版中文：`看见意义，说出英语。`
- 新版英文：`See the Meaning. Speak the English.`

**产品定义**: `AI-native visual dialogues for language learning`

**核心叙事**: We are not replacing movie clips with AI clips. We are creating AI-native visual dialogues where meaning becomes visible.

**内容三维度**: Tension（张力）+ Thought（思想）+ Immersion（沉浸）

**视频三层结构**:
1. Reality Layer — 现实对话层（物理场景锚定）
2. Meaning Layer — 意义可视化层（话语改变画面）
3. Learning Layer — 语言学习层（key sentence, shadowing, speaking practice）

## 品牌命名约定

- **对外主品牌名统一使用 `MofunShow`**
- **AI 伙伴名统一使用 `Elian`**
- 对外完整产品名可按上下文使用 `MofunShow` 或 `MofunShow - Elian`
- `MofunGenAI` 属于历史内部工程名，可暂时保留为目录名或工程名，但**不再用于新的用户可见文案、应用展示名或新的对外命名**

## 学习流程（4 步）

1. **Elian 介绍场景** — 场景理解检查 + 语言点讲解
2. **观看完整对话视频** — 可交互字幕
3. **选角色 + 逐句跟读** — 录音 + STT + Elian 反馈
4. **Elian 总结与讨论** — 思想讨论 + 配音作品生成

## Elian 双模式 AI 系统

- **Mode 1 - Learning Partner**: 专业教练角色，结构化反馈，发音指导
- **Mode 2 - Director Friend**: 轻松影视讨论，剧情分析，创意配音技巧
- **上下文感知切换**: 基于用户活动（练习 vs 聊天）和语气

## 核心创新（Elian 系统）

**问题**: AI 生成短剧（60分）< 电影（100分）
**解决方案**: AI 短剧（60）+ Elian 陪伴（40）= 完整体验（100）
**原理**: 语言的功能是交流。Elian 的存在激发交流欲望，弥补 AI 内容质量差距，让学习不再孤独。

## 竞品对比

- **vs. Duolingo**: 不是游戏化练习，而是视频沉浸式学习
- **vs. 流利说**: 不是 AI 对话课程，而是和 AI 一起看视频
- **vs. 原版魔方秀**: 不只是配音工具，而是伙伴学习 + AI 升级

## 历史背景

### 旧系统（2013-2020）
- 400万注册用户，电影/电视片段配音（版权问题）
- PHP 后端 + iOS/Android 原生 App
- 2020 年停止迭代

### 重建原因（2025 Reborn）
1. 版权风险：电影内容侵权需要完全替换
2. 高成本：传统基础设施不可持续
3. 技术债：PHP 后端无法支持现代 AI 功能
4. 市场变化：用户消费从电影转向短剧/短视频
